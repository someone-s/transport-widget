# Rail Delivery Group

Represent britain\'s train operators, provides live tracking data for all national rail services in Britain.

### API keys
- API access to Rail Delivery Group is monetarily free, but requires an account
- Follow the below steps to obtain the necessary API keys
    1. [Register an account on Rail Data Marketplace for personal use](https://raildata.org.uk/registerPartner)
    2. [Subscribe to "Reference Data" product, this is the Stops API key](https://raildata.org.uk/dataProduct/P-c73f0d2a-c233-497d-846b-8354e2cac326/specification)
    3. [Subscribe to "Live Departure Board - Staff Version" product, this is the Arrivals API key](https://raildata.org.uk/dataProduct/P-53613c24-0205-4d3b-919a-b338858e130e/specification)
        - Staff version provide more indepth information on departures
        - Use of this API is **not** restricted to staff
